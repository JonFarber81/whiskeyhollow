# Whiskey Hollow

*A Prohibition-era Kansas City bootlegger roguelike.*

It's 1920s Kansas City. Booze is illegal and the money is very good. You run a small bootlegging outfit: you move hooch, hire a crew, fight rival gangs and crooked cops, and work your way up through the city's criminal factions. When you die, the run is over.

Whiskey Hollow is a turn-based, tile-based roguelike written in Python on top of [python-tcod](https://github.com/libtcod/python-tcod). The UI is text-mode with an amber-and-sepia noir palette.

## At a glance

| | |
|---|---|
| **Setting** | Kansas City, 1920–1933 |
| **Genre** | Roguelike RPG, permadeath |
| **Classes** | Brawler, Con Man, Smuggler, Fixer |
| **Factions** | Pendergast Machine, Union Station Crew, River Market Syndicate, The Jazz District Co., Kansas City PD (Corrupt) |
| **Ways to win** | Retire with $50,000, or become Boss of a faction while holding 3 districts |
| **Tech** | Python 3.11+, tcod, numpy |
